## 一个保留证据的系统构建者

我叫 **Zhiyuan**，计算机科学与技术硕士研究生。

我的工作位于大模型应用、可靠性验证与 Agent 工作流的交界处。我喜欢从一个真实问题出发，把模型接入检索、工具和记忆；然后继续追问：**这个输出依据什么产生，能否复现，失败时能否定位，下一位使用者能否接着工作？**

研究、工程与写作逐渐汇成了同一个长期项目：

- **可靠 AI**：用检索证据、语义几何与反馈式建模识别低置信输出。
- **可审计 Agent**：把目标、权限、证据和验收条件写进工作流合同。
- **知识基础设施**：把多年笔记、算法练习、项目记录和研究判断组织成可搜索、可连接、可继续生长的系统。

> 我关心模型能做什么，更关心我们凭什么相信它的结果。
